술값배틀 2026 · 자동 갱신 시각 & 미장/국장 D-day 표시 패치
=========================================================

교체할 파일 2개:
  index.html
  assets/style.css

1. GitHub https://github.com/kssksskss811-glitch/sool-battle-2026 접속
2. Code > Add file > Upload files
3. 압축 푼 파일에서 index.html 파일과 assets 폴더를 업로드
   (assets 폴더 안에는 style.css 파일만 들어 있습니다)
4. 파일 경로가 index.html, assets/style.css 인지 확인한 다음 Commit changes
5. Actions 에서 최신 실행 녹색 체크를 확인하고 기존 사이트 접속
6. Ctrl+Shift+R 강력 새로고침 (모바일이면 탭 새로 열기)
   --> 제목 옆에 미장·국장 거래일 D-day, 바로 아래에 종가 수집 예약 시각 표시

이번 패치에서 바꾸지 않는 파일:
  assets/app.js, data/prices.json, data/history.json, scripts/*, .github/*
즉, 주가 수집·순위 계산·그래프는 기존 코드 그대로입니다.
