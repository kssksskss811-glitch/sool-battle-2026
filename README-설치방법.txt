# 술값배틀 2026 — 1월부터 순위 변동 그래프 추가 패치

이 패치는 **기존 GitHub Pages 사이트를 유지**하면서 아래 기능만 수정합니다.

- 밝은 한 화면 대시보드 (PC 큰 화면 기준)
- 은지·동민 공동 1위 (다음은 3위)
- 사람마다 고유 배지 및 이름 색상
- 플러스 수익률 빨강 / 마이너스 파랑
- 오른쪽 위 술값 후보 3인 요약
- 오른쪽 아래 **8개 선을 동시에 보여주는** 2026년 순위 변동 Bump Chart
  (은지/동민 엔비디아 공동 1개 + 나머지 7개)
- 차트 기간 최근 7일 / 최근 30일 / 2026년 전체
- 2026-01-01부터 역사적 **실제 확정 종가** 조회 및 순위 복원
- 최초 복원 후 기존 GitHub Actions가 매일 data/history.json을 누적 기록
- 데이터 미수집 시 가짜 차트를 표시하지 않고 오류 표시

## GitHub에 올릴 파일 (정확히 5개)

업데이트 ZIP 내부의 **폴더 구조를 유지**해서 다음 파일만 기존 저장소에 반영하세요.

1. `index.html`
2. `assets/app.js`
3. `assets/style.css`
4. `scripts/backfill_history.py`  ← 새 파일
5. `scripts/update_prices.py`     ← 기존 파이썬 파일 교체

**중요: 저장소의 `data/prices.json`, `data/history.json`, `.github/workflows/update.yml`은 삭제/덮어쓰지 마세요.**
이 배포 패키지에는 이 데이터 파일들과 워크플로가 들어 있지 않습니다.

GitHub 계정의 `sool-battle-2026` 저장소에 반영한 뒤:
`Actions → 술값배틀 · 종가 자동 수집 + 사이트 배포 → Run workflow (main)`
성공한 실행의 `마감된 시세 조회하고 순위 이력 저장` 로그에서

`[HISTORY OK] 2026-01-01 ~ YYYY-MM-DD 복원 N일`

메시지가 나오는지 확인하세요. 최초 과거 데이터 수집은 평소보다 오래 걸릴 수 있습니다.
한 번 복원되면 `[HISTORY] ... 이미 있어 재조회 생략`으로 바뀝니다.

## 순위 계산 기준

시작 단가: 사용자 최초 제시 금액 그대로 고정. 각 날짜마다 아래 *확정 종가* 사용:

- 한국 주식: 해당 한국 날짜 오후 15:30까지 종료된 가장 최근 거래일 종가
- 미국 주식: 한국시간 같은 날 오후 17:30까지 마감된 가장 최근 미국 거래일 종가
- 비트코인: 한국시간 같은 날 오전 09:00에 확정된 업비트 KRW-BTC 일봉 종가

차트는 한국시간 매일 17:30을 기준으로 **그때까지 확정된 값만 사용**합니다.
미국 장은 시차 때문에 일반적으로 한국 날짜의 전 거래일 종가입니다.
휴장일은 기존 확정 종가를 이어서 사용하지만 **새로운 시세를 가상 생성하지 않습니다**.
2026-01-01은 양국 주식시장 휴장이므로 2025년 말 마지막 거래일 종가를 사용합니다.

동일한 수익률은 공동 순위로 처리합니다 (1위, 1위, 3위).
그래프에는 은지·동민을 1개 선으로 합쳐 총 8개 선을 표시합니다.

## 과거 데이터 출처 및 제한

- 미국: Yahoo Finance 비공식 `chart` 일봉 API
- 국내: 네이버 금융 비공식 `fchart.stock.naver.com` 일봉 API
- 비트코인: 업비트 공식 일봉 API, 페이지별 최대 200개 조회

외부 조회가 차단되거나 과거 데이터가 부족하면 과거 순위 복원을 실패 처리하고
**기존 데이터를 유지**합니다. 임의 숫자나 샘플 데이터로 순위를 채우지 않습니다.
역사적 시장 종가는 거래소별 시차·분할·수정 공시에 따라 검증이 필요합니다.

기존 데이터 갱신 작업이 성공하더라도 과거 수집이 실패할 수 있으므로
`[HISTORY WARN]` 로그도 확인하세요.

추가 pip 패키지는 사용하지 않습니다 (Python 3.11+).
