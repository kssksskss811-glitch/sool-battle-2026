술값배틀 2026 — 주간 순위 그래프/색상 개선 패치

수정 파일 (딱 3개)
- index.html
- assets/app.js
- assets/style.css

수정 내용
1. 매일 286포인트 -> 한 주에 한 포인트. 기본 최근 12주, 최근 8주, 2026 전체.
2. 주간 대표 기록은 한국시간 토요일(그 주 미국 금요일 종가가 반영된 시점)입니다.
   최신 주에 토요일 기록이 아직 없다면 그 주의 최신 확보 기록을 사용합니다.
   이 로직은 주가를 다시 조회하지 않고 기존 data/history.json의 실제 순위 이력을 활용합니다.
3. 각 참가자(은지·동민은 같은 종목이라 같은 차트 선으로 묶음)별 고대비 컬러.
4. 한 그래프에서 8개 계단형 순위선(1위가 위쪽)을 표시합니다.
5. 오른쪽 범례의 사람을 클릭하면 그 사람의 선만 강조되고 다시 클릭하면 전체 선으로 돌아옵니다.
6. 주가 수집 관련 .github, scripts, data 파일은 건드리지 않습니다.

설치 방법
1) 이 ZIP 압축을 풉니다.
2) GitHub 저장소 sool-battle-2026 -> Code -> Add file -> Upload files
3) 압축을 푼 폴더의 index.html 과 assets 폴더를 같이 드래그합니다.
   업로드 경로가 반드시 index.html, assets/app.js, assets/style.css 인지 확인합니다.
4) Commit changes 를 누릅니다.
5) Actions에서 자동 배포가 초록 체크로 끝나면 기존 사이트를 열고 Ctrl+Shift+R을 누릅니다.

설치 시 주의
- 기존 .github / scripts / data 폴더를 삭제하거나 덮어쓰지 마세요.
- 사이트 화면은 history.json에 기록된 과거 종가 순위만 사용하며, 임의의 주간 순위를 생성하지 않습니다.
- 주말/휴장일에는 직전 확정 종가가 유지되므로 같은 순위가 연속해서 나타날 수 있습니다.
- 이미 저장된 과거 이력의 종가 정확성은 이 프론트엔드 수정만으로 검증되지 않습니다.

문의할 때는 GitHub Actions 실행 결과 화면을 보내주세요.
